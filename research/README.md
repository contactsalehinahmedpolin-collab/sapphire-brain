# Lead research files
One file per lead: research/<lead_id>.md, written by Claude before the lead is sent.
Sections: Snapshot · What's broken right now (with sources) · What it costs them · Our 3 fixes (order / margin / repeat) · Best angle for the first line · Watch-outs.
When done, Claude sets `research=done` in pipeline/new_leads.csv (variant column: `...;research=done`) and may improve first_line, pain, free_idea.
